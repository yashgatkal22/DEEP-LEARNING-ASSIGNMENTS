This repository contains practical implementations of various deep learning techniques, providing hands-on experience with neural networks, model training, evaluation, and optimization.

---

## 📚 Laboratory Assignments

| Sr. No. | Experiment / Assignment | Overview |
|:---:|---|---|
| 01 | **Implement a Perceptron from Scratch** | Implement a single-layer perceptron using NumPy, train it on linearly separable data, and visualize its decision boundary. |
| 02 | **Feedforward Neural Network** | Build and train a Multi-Layer Perceptron (MLP) using a deep learning framework and evaluate its performance. |
| 03 | **Regularization Techniques** | Explore L2 regularization and Dropout to understand their impact on model generalization and overfitting. |
| 04 | **Activation Functions** | Compare Sigmoid, Tanh, and ReLU based on training performance, accuracy, and gradient behavior. |
| 05 | **Convolutional Neural Network** | Develop a CNN for image classification and compare its performance with a traditional MLP. |
| 06 | **RNN / LSTM for Text Classification** | Implement an LSTM-based model for binary sentiment classification using the IMDB dataset. |
| 07 | **Transfer Learning with Pretrained CNNs** | Fine-tune pretrained ResNet50 and VGG16 architectures for image classification. |
| 08 | **Hyperparameter Tuning and Model Comparison** | Experiment with different hyperparameters and compare model configurations using TensorBoard. |

## 🎯 Learning Objectives

Through these laboratory assignments, the following concepts and practical skills are explored:

- Understand the fundamentals of artificial neural networks and perceptrons.
- Build, train, and evaluate feedforward neural networks.
- Apply regularization techniques to improve model generalization.
- Understand activation functions and gradient-related problems.
- Develop CNN architectures for image classification.
- Implement recurrent neural networks for text classification.
- Apply transfer learning using pretrained deep learning models.
- Perform hyperparameter tuning and compare model performance.
- Understand and analyze training metrics, accuracy, and loss.

## 🚀 Getting Started

Follow these steps to clone the repository and run the assignments locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/DEEP-LEARNING-ASSIGNMENTS.git
```

### 2. Navigate to the Repository

```bash
cd DEEP-LEARNING-ASSIGNMENTS
```

### 3. Install Required Libraries

Install the libraries required for the assignments:

```bash
pip install numpy pandas matplotlib tensorflow torch torchvision
```

### 4. Run an Assignment

Navigate to the required assignment folder and execute its Python file:

```bash
python filename.py
```

> **Note:** Required libraries and datasets may vary depending on the assignment.
